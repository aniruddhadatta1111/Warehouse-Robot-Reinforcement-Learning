\# Deep Reinforcement Learning for Warehouse Robot Navigation



\## Overview



This project explores Reinforcement Learning through both a benchmark environment (Taxi-v3) and a custom warehouse robot navigation environment. The objective is to train intelligent agents that learn optimal decision-making strategies through interaction with their surroundings using reward-based learning.



The project compares traditional Q-Learning with Deep Q Networks (DQN) and demonstrates how reinforcement learning techniques can be applied to autonomous navigation and task completion problems.



\## Key Features



\* Q-Learning implementation in Taxi-v3 environment

\* Deep Q Network (DQN) implementation using PyTorch

\* Experience Replay Buffer

\* Target Network for stable learning

\* Epsilon-Greedy Exploration Strategy

\* Custom Warehouse Robot Environment

\* Autonomous package pickup and delivery simulation

\* Performance evaluation through reward and success-rate analysis

\* Agent behavior visualization and comparison

\## Project Structure



\### Gym\_Taxi\_Environment.ipynb



Implements and compares classical Q-Learning and Deep Q Networks (DQN) in the Taxi-v3 environment to study agent learning and decision-making.



\### warehouse\_custom.ipynb



Implements a custom warehouse environment where an autonomous robot learns navigation, package pickup, and delivery tasks using Deep Reinforcement Learning.
